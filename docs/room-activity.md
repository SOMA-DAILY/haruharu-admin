# 방 활동 대시보드 (#29)

`/sessions/:id`의 방 기본 정보 아래에 활동 요약·참여자별 집계·활동 목록을 표시한다.
Figma의 방별·일차별 영상 아카이브 구성을 기존 Ant Design 화면에 맞게 적용했다.

- 전체 활동 / 영상 모아보기 / 채팅 / 반응 / 익명질문 탭
- 방 선택표: 선택한 사람 → 선택 상대(방 가명 + ID), 실제 매칭/상호 선택/선택 없음 표시. 활동 필터와 별개로 방 전체를 표시한다.
- 전체 기간 또는 일차, 참여자, 최신순·오래된순 필터
- 썸네일 클릭으로 영상 재생, 썸네일 없음·로딩 실패·재생 실패 안내
- 영상 모아보기는 DAY → 실제 slot_start(1시간 슬롯) → 참여자 영상 순서로 여러 슬롯을 나란히 배치한다. 영상은 100건씩 이어 불러온다.
- 참여자별 영상·채팅·반응 송수신·질문 수신 수
- 익명질문은 발신자·수신자(방 가명 + 사용자 ID), 질문·답변만 한 카드에 표시. 별도 답변 활동/집계 없음(일반 사용자 익명성 유지)
- 목록은 24건씩, 끝에 닿으면 이어서 불러온다(무한 스크롤, #50). 요약은 불러온 목록이 아닌 선택한 일차·참여자의 전체 집계

## 필요한 서버

BE #434의 `GET /rooms/{id}/activities`, `GET /rooms/{id}/activity/summary`가 필요하다.
미배포/조회 실패를 활동 0건으로 숨기지 않고 오류와 재시도를 표시한다.
백엔드는 S3 비공개 미디어 서명을 위해 AWS_S3_BUCKET 및 런타임 S3 읽기 권한이 필요하다.

반응은 현재 남아 있는 반응이며 취소·교체 이력은 아니다. 그룹채팅만 조회한다.
운영 데이터와 테스트 데이터를 혼합하지 않으며 제품에 목업 데이터나 인증 우회를 넣지 않는다.
