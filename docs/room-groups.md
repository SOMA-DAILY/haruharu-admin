# 방 목록 기수 묶음

- 운영방/테스트방/전체 필터, 기본 운영방. 상태/예정일과 조합하며 URL에 유지한다.
- 최신 생성한 기수를 먼저 표시하고 기본으로 펼친다. 이전 기수와 기수 미지정은 접고 펼칠 수 있다.
- 각 기수의 표가 서버에서 독립적으로 페이지를 조회한다. 접힌 기수의 방/활동 요약을 불러오지 않는다.
- 기수 추가는 목록 안에서 하고, 새 방 생성은 최신 기수를 기본 선택한다. 서버도 미지정 요청에는 최신 기수를 사용한다.
- 여러 방(최대 100개)을 선택해 기수·운영/테스트 구분을 일괄 지정한다. 둘 중 하나만 바꾸는 것도 가능하다. 필터가 바뀌면 선택을 비워 숨겨진 방을 실수로 수정하지 않는다.
- 기존 방은 구분 미설정/기수 미지정으로 유지한다. 전체 보기에서 운영자가 분류하며 날짜/ID로 추정하지 않는다.
- 방 상세에서도 기수와 구분을 확인·변경한다. CS에게는 쓰기 컨트롤이 나타나지 않는다.
- 새 API는 BE #536에 정의. 관리자 서버와 추가 스키마 배포가 완료된 뒤 웹을 배포한다.

검증은 Node22 lint/build/test 및 로컬 실제 관리자 API·독립 PostgreSQL QA 스키마에 연결한 Chromium으로 수행한다. 운영/테스트 필터, 23개 방의 페이지 이동, 기수 간 이동, 기존 미설정, 기수 추가/새 방 기본값, 1024/1440/1920px, 새로고침 필터 유지, 런타임 오류를 확인한다.
